# TS Medical Aesthetics — Concept Homepage

Premium single-page concept for **TS Medical Aesthetics / Trend Sassy** (Mississauga).

Built to sell a ~$5k website engagement: Three.js WebGL hero veil, GSAP ScrollTrigger (pinned device rail + scrubbed before/after), treatment pathways, clear consult CTA.

## Stack

- Next.js 15 (static export)
- GSAP + ScrollTrigger
- Three.js + React Three Fiber (custom rose-field shader)
- Tailwind CSS

## Promise map

1. Device / treatment proof → horizontal pin rail (`#proof`)
2. Treatment pathways → interactive tabs (`#pathways`)
3. Clear consult CTA → `#consult`
4. Scroll-scrub before/after → `#results`

## Dev

